# KFC 媒体中枢 · v4 重制 · 规格表（Step 1+2 依据文档）

> 本文件是「完整重构为商用级运维控制平面」的**唯一执行依据**（对应共享需求文档第 2 步要求）。
> 全部结论基于源码实测：后端 `openrepo/app/app.py`（Flask 单文件，≈3.3 万行）+ 前端 `index.html`（单文件 vanilla JS，≈2MB，~200 个 `/api/*` 端点）。
> **技术栈结论（Step 1）**：沿用现有栈——Flask 后端 + 单页 vanilla JS 前端 + CSS 变量驱动主题。**不引入 React/Tailwind 构建链**（会破坏零构建部署模型与现有 PT/MT/Emby/Edge/JWT/Bot 链路）。新前端改为**模块化静态资源**（`/static/v4/*`），由 `app.py` 新增只读接口 + 静态路由支撑，旧 `index.html` 保留至 v4 验收通过再切换 `/`。

## 表 2 · JWT 六态状态机 + 全局健康三态 + 数据新鲜度

### 2.1 JWT 六态状态机
| 状态 | 展示（颜色+图标+文字） | 可用动作 | 超时/转换规则 |
|---|---|---|---|
| 有效 | 绿 · 🟢 · 有效 | 查看详情/重置 | 临期<5m 自动转「临期」 |
| 临期<5m | 黄 · 🟡 · 临期(剩 Xs) | 立即刷新 | 过期自动转「刷新中」 |
| 刷新中 | 蓝(呼吸) · 🔵 · 刷新中… | 无（禁用重复） | **>90s 自动转「失败」并带原因** |
| 失败 | 红 · 🔴 · 失败：<原因> | 重试/重置凭据/查看日志 | 原因∈{凭据过期/网络超时/站点拒绝/回写失败/未知} |
| 已降级 | 橙 · 🟠 · 已降级(用缓存) | 重试 | 恢复有效自动升 |
| 无凭据 | 灰 · ⚪ · 无凭据 | 配置凭据 | — |

> 任何中间态（刷新中/临期）挂起超 90s → 强制「失败」+ 具体原因，**禁止无限期「自动恢复中」**。

### 2.2 全局健康三态
| 态 | 展示 | 规则 |
|---|---|---|
| 全部正常 | 绿 · 全部正常 | 所有域 PT/MT/Emby/看门狗 OK |
| 部分可用 | 黄 · 部分可用（明确写出哪部分可用）| 至少一域降级但非全断 |
| 异常 | 红 · 异常（点开看详情）| 任一核心域失败 |

### 2.3 数据新鲜度
- 默认阈值 **120s**（可配）；每数据卡 + 全局头显示「更新于 Xs 前 / 下次刷新倒计时 / 手动刷新」。
- 超阈值 → 标记「数据陈旧」+ 样式 + 文字提示；**禁止静默展示旧值**。
- 写操作（清空/重置/自愈）：确认 + 幂等 + 防重复提交 + 写审计 + 可撤销。
