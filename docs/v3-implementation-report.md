4. **KFC2 实时观看专项**：
   - **诊断真因**：`_emby_inst_http('emby_adult')` 连接正常（System/Info + Sessions 都返回真实数据），后端 `emby_sessions()` 双实例并发聚合逻辑**本身正确**；当前 `n=0` 是因为**当前无人在播放**（两实例都无 `NowPlayingItem`），不是 bug。
   - **模拟双实例同时播放验证**（只读 monkeypatch）：`by_server={emby:KFC n=1, emby_adult:KFC2 n=1}`，数据完全隔离、画质解析正确、零串台。
   - **前端修复**：实时播放面板改为**按实例显示在线/离线/观看人数**，即使无人播放也显示 KFC2「在线·无人观看」——解决用户无法区分「KFC2 正常但没人看」与「KFC2 挂了」的问题。
5. **原有总览完整保留**：新驾驶舱挂在 `#view` 之外（main 直接子元素），原总览（ovm 13 列可拖拽网格）在其下方完整保留，零功能丢失。
